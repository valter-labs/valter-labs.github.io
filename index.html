rclone - backup pessoal no Google Drive

Português

Esta é a ferramenta pessoal de backup no Google Drive do Valter Ribeiro (valter-labs), baseada no rclone.

É de uso pessoal: só o dono a utiliza, para copiar os próprios arquivos para a própria conta do Google Drive. Não é um serviço oferecido ao público.

A ferramenta pede apenas o escopo drive.file. Com ele, ela só consegue ver e alterar os arquivos que ela mesma criou no Google Drive. Ela não tem acesso a nenhum outro arquivo da conta.

Leia a política de privacidade.

English

This is the personal Google Drive backup tool of Valter Ribeiro (valter-labs), based on rclone.

It is for personal use only: only its owner uses it, to copy his own files to his own Google Drive account. It is not a service offered to the public.

The tool requests only the drive.file scope. With it, the tool can only see and change the files that it created itself in Google Drive. It has no access to any other file in the account.

Read the privacy policy.
